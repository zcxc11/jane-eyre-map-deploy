# 《简·爱》人物关系图 · Jane Eyre Character Map

一个**零依赖、纯静态**的开源阅读辅助站点：用一张可交互的人物关系图、一张思维导图和一批补充材料，读懂夏洛蒂·勃朗特的《简·爱》。

> 「你以为，因为我穷、低微、不美、矮小，我就没有灵魂、没有心吗？」

在线预览：将仓库部署到 GitHub Pages 后即可访问（见下文「部署」）。

## 功能

| 板块 | 说明 |
| --- | --- |
| **人物关系图** | 21 位人物、22 条关系，按五段场景着色。点击人物高亮其全部关系，右侧展开人物速写、关系清单与结局；支持按家族/场景筛选，`?c=Roch` 式深链接可直达某个人物 |
| **六组关键关系** | 简×罗切斯特、罗切斯特×伯莎、简×里德太太、简×海伦、简×圣约翰、罗切斯特×布兰奇——每组附英文原句、中译与章节 |
| **五段人生地理** | 盖茨海德 → 洛伍德 → 桑菲尔德 → 沼泽居 → 芬丁的时间线，含章节号、年龄与关键事件 |
| **思维导图** | 情节 / 主题 / 意象 / 人物 / 名句 / 背景 六个分支，运行时布局渲染，点击标签可聚焦 |
| **人物速查表** | 21 人 × 身份 / 场景 / 关键关系 |
| **结局名单** | 一场大火之后的「离场」与「留下」 |
| **经典台词** | 12 句名句，附章节、语境注解，可按人物筛选 |

技术特点：

- 无构建、无第三方库、无网络请求（不加载任何远程字体/脚本），克隆即用；
- 原生 SVG 渲染，布局在浏览器端计算；
- 响应式（桌面 / 平板 / 手机），支持键盘操作与 `Esc` 复位，遵循 `prefers-reduced-motion`；
- 打印样式友好。

## 快速开始

```bash
git clone https://github.com/<your-name>/jane-eyre-map.git
cd jane-eyre-map
python3 -m http.server 8000     # 或任意静态服务器
# 打开 http://localhost:8000
```

直接双击 `index.html` 也可以运行（脚本均为普通 `<script>`，无跨域限制）。

## 修改内容

所有人物、关系、台词、时间线、思维导图数据都集中在 **`js/data.js`**：

- 加一个人物：在 `JE.characters` 里加一条（含坐标 `x/y/w/h`，坐标系为 1720 × 1300 的 SVG 视口），再在 `JE.relations` 里补关系；
- 改文案：直接编辑对应字段，页面与图表自动同步；
- 关系线标签位置可用 `t`（0–1）与 `bow`（弯曲方向）微调。

如果只是改文字，不需要懂 HTML/CSS/JS。

## 部署到 GitHub Pages

**方式一（推荐，Actions 自动部署）**

1. 把仓库推到 GitHub（默认分支 `main`）；
2. 仓库 Settings → Pages → Source 选 **GitHub Actions**；
3. 推送即自动部署（工作流已内置：`.github/workflows/pages.yml`）。

**方式二（从 main 分支直接发布）**

Settings → Pages → Source 选 *Deploy from a branch* → 选 `main` / root。

部署后地址为 `https://<your-name>.github.io/jane-eyre-map/`。
